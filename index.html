01Things I’ve built

Consilium

Go · TCP · Ollama

Several LLMs argue about a question until they agree. A hub coordinates concurrent workers over a custom JSON-over-TCP protocol. Each worker runs a different local model, and consensus is scored by confidence-weighted agreement, with configurable timeouts, thresholds and an optional verification round.

Terminal Fit Recorder

Go · Bubble Tea · SQLite · MCP

A full-screen terminal app for logging workouts and generating training plans from each person’s history through Claude, Codex or OpenCode, and from Telegram too. It turns freeform notes (Ukrainian included) into structured workouts and exposes the history to AI assistants as an MCP server.

~12K lines of Go, a third of it tests · race-detector CI · checksummed releases for Linux, macOS and Windows

Kafka Broker

Go · Kafka wire protocol

A toy broker written from scratch that speaks Kafka’s binary protocol over TCP and serves concurrent clients. It answers topic queries by parsing the KRaft cluster metadata log. I also wrote an HTTP/1.1 server and a small shell the same way, through CodeCrafters.
